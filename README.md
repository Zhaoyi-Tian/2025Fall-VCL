## Task 1：Parallel Coordinates Visualization

 <img src="images\51.png" alt="51" style="zoom: 25%;" />



**数据预处理（归一化）**：首先遍历所有汽车数据，找出 7 个属性（如马力、重量等）各自的最大和最小值。通过 `Normalize` 函数将不同单位的数值全部缩放到 $[0, 1]$ 空间，确保它们能整齐地显示在垂直轴上。

**坐标映射与连线**：将屏幕水平平分为 7 条纵向轴。每一辆车对应一条贯穿所有轴的**折线**：折线在每条轴上的高度由该属性的归一化数值决定。

**视觉强化与优化**：

- **颜色编码**：根据“油耗（mileage）”的高低对线条进行渐变着色（钢蓝到棕色），便于观察属性间的相关性。
- **性能缓存**：使用 `rendered` 标志位，只有在数据更新或强制要求时才重新渲染，避免不必要的计算。

## Task 2：**Flow Visualization**

<img src="images\52.png" alt="52" style="zoom: 50%;" />

**流线追踪**：针对图像中的每一个像素点，根据向量场（`field`）的方向，分别向**正向**和**反向**延伸出一段有限长度的“流线”（Streamline）。

**噪声采样与平均**：在追踪这条流线的过程中，读取背景噪声图像（`noise`，通常是白噪声）上对应位置的像素值，并把路径上所有的值加起来**求平均**。

**生成纹理**：由于同一条流线上的像素点会共享大部分噪声采样点，平均后的结果会在视觉上形成沿着向量场方向延伸的**条纹状纹理**。
