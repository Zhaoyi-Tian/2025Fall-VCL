## Task 2：**Mass-Spring System**

效果：

![image-20251202191857577](images\image-20251202191857577.png)

通过基于牛顿迭代的隐式欧拉方法求解质量弹簧系统动力学。主要流程如下：

1. **初始化**：获取当前时刻位置`p_t`和速度`v_t`，使用显式欧拉预测作为牛顿迭代初值`p_new = p_t + v_t·dt`。

2. **牛顿迭代求解非线性方程**（最多20次）：
   - **构建残差G(p)**：根据隐式欧拉公式，残差定义为惯性力项减去内外力之和
     ```
     G(p) = M/Δt²·(p - (p_t + v_t·Δt)) - (F_spring + F_gravity)
     ```
   - **计算弹簧内力**：遍历所有弹簧，根据胡克定律计算拉力并添加到对应节点的残差中
   - **检查收敛**：计算残差L2范数，小于阈值则提前终止迭代
   - **构建雅可比矩阵J**：包含三部分贡献：
     - 固定节点：雅可比为单位阵，强制位移不变
     - 惯性项：对角阵 M/Δt²
     - 弹簧切线刚度矩阵：推导得到的精确解析形式
   - **求解线性系统**：使用Cholesky分解求解 `J·Δp = -G`
   - **步长控制**：限制Δp的最大步长为0.1，并应用阻尼系数0.98
   - **更新位置**：`p_new += Δp·缩放因子·阻尼`

3. **状态更新**：迭代结束后，根据新位置更新速度`v_{t+1} = (p_new - p_t)/Δt`并更新系统位置。
